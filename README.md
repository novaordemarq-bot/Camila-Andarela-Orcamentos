# ✈️ Camila — Andarela Tur (Gerador de Orçamentos)

Aplicativo web e mobile (PWA) criado para a **Camila (Andarela Tur — Viagens e Vistos)** gerar orçamentos de Visto Americano, Passaporte, eTA Canadense, ESTA e serviços consulares sem precisar fazer fórmulas manuais no Excel.

## ✨ Funcionalidades
- **As 8 Tabelas da Planilha + Modelos Extras com 1 clique**
- **Montador Automático por Perfil do Cliente** (Mistura Sem Entrevista + Com Entrevista + Passaporte c/ 50% OFF + Taxas Consulares e GRU)
- **Motor Inteligente de Descontos** (10%, 15%, Tabela Progressiva SE 2 a 6 pessoas, Desconto Criança R$ 50 e Valor Fixo — calculado sempre apenas sobre a assessoria)
- **Cálculo Automático de Parcelamento no Cartão** (2x a 5x conforme faixa de valor)
- **Exportação Instantânea:**
  - 📄 **PDF Oficial em Alta Resolução (.pdf)**
  - 🖼️ **Imagem Pronta para WhatsApp (.png)**
  - 📲 **Compartilhamento Direto para o WhatsApp no Celular**
  - 💬 **Texto Formatado para WhatsApp**
